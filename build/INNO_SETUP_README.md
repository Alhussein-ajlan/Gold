# دليل استخدام Inno Setup للمحاسب الذكي BenAjlan

## المتطلبات

1. **تثبيت Inno Setup**
   - قم بتحميل Inno Setup من: https://jrsoftware.org/isdl.php
   - اختر النسخة الكاملة (Inno Setup with Preprocessor)
   - قم بتثبيته في المسار الافتراضي

2. **إضافة Inno Setup إلى PATH**
   - افتح إعدادات النظام > متغيرات البيئة
   - أضف المسار: `C:\Program Files (x86)\Inno Setup 6` إلى متغير PATH
   - أو استخدم المسار الكامل عند التشغيل

## طريقة البناء

### الطريقة الأولى: استخدام build.bat (موصى بها)
```cmd
build.bat
```

### الطريقة الثانية: خطوة بخطوة
```cmd
# 1. بناء التطبيق
npm run build

# 2. إنشاء المثبت باستخدام Inno Setup
npm run build:inno
```

### الطريقة الثالثة: بناء كامل بأمر واحد
```cmd
npm run build:full
```

## ملفات الإخراج

بعد البناء الناجح، ستجد:
- `GoldNew/BenAjlan-Setup-3.2.3.exe` - ملف التثبيت النهائي
- `GoldNew/win-unpacked/` - ملفات التطبيق غير المضغوطة

## تخصيص المثبت

لتخصيص شاشة التثبيت، قم بتعديل ملف `build/installer.iss`:
- تغيير الصور: استبدل WizardImageFile و WizardSmallImageFile
- تعديل النصوص: قسم [CustomMessages]
- إضافة ملفات: قسم [Files]
- تخصيص الأيقونات: قسم [Icons]

## استكشاف الأخطاء

### خطأ: iscc command not found
**الحل:** تأكد من تثبيت Inno Setup وإضافته إلى PATH

### خطأ: Cannot find win-unpacked directory
**الحل:** قم بتشغيل `npm run build` أولاً

### خطأ: License file not found
**الحل:** تأكد من وجود ملف LICENSE.rtf في المجلد الرئيسي

## ملاحظات مهمة

- يجب بناء التطبيق أولاً باستخدام `npm run build` قبل إنشاء المثبت
- ملف installer.iss يبحث عن الملفات في `GoldNew/win-unpacked/`
- المثبت يتطلب صلاحيات المسؤول للتثبيت
- يتم حفظ البيانات في مجلد التطبيق ويمكن الاحتفاظ بها عند الإزالة
